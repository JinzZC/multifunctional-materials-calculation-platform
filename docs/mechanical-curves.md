# 通用力学曲线模块

从左侧导航“通用力学曲线模块”进入。仅提供拉伸分析，不包含弯曲、IFSS 或热分析。

## 使用流程

1. 选择变形来源，输入试样尺寸。截面可选矩形、圆形或直接输入截面积。
2. 选择拟合区间依据：工程应变百分数或峰值力百分数。默认 0.05%–0.25% 仅为可编辑初值，不代表所有材料的标准区间。
3. 指定新文件的力与变形单位，确认文本小数分隔符。文件中的单位若与所选单位冲突会拒绝导入。
4. 点击“批量导入文件”，或“自定义映射导入”选择工作表、表头行和源列。同一批使用相同尺寸、来源和导入设置；不同尺寸可导入后逐条调整。
5. 在“当前曲线”选择记录。修改左侧参数后，点击“将参数应用到所选曲线”。修改待应用时禁止保存及导出，避免混用新参数和旧结果。多选时统一应用尺寸、拟合参数、日期和备注，但保留各自样品名。
6. Ctrl / Shift 多选可叠加曲线；统计按变形来源、拟合方式及区间分组。统计仅针对所选试样，不推断材料或批次是否相同。
7. 需要断裂应变时，逐条人工确认断裂点号（从 1 开始），也可在单条曲线上双击选点，再应用参数。断裂点不能早于曲线峰值。未确认时只输出峰值和记录末点应变。
8. 保存所选结果，或导出 Excel / CSV / PDF。历史可按样品和备注筛选，载入后按当前算法重算并对比。

批量导入在后台执行，单文件失败不会终止后续文件；错误保留在导入日志。取消在当前文件处理完成后生效。当前曲线移出操作不删除已保存历史；删除历史需要在历史页确认。

## 输入与单位

支持 XLSX、XLSM、CSV、TXT、TSV。CSV 使用逗号分列，TSV 使用制表符；TXT 分隔符由现有表格读取器识别。文本支持 UTF-8、GB18030。Excel 可选工作表和表头行。

| 字段 | 支持的单位 | 内部保存单位 |
|---|---|---|
| 总力 / 载荷 | N、kN、cN、mN | N |
| 实测工程应变 | %、mm/mm | mm/mm |
| 标距内伸长、横梁位移 | mm、μm | mm |

例如，`strain(%)`、`force(kN)` 可自动识别。多个候选列或仪器专用列名需自定义映射。原始数据应按采集顺序单调加载，至少 5 点；拟合区间在首次峰值之前至少包含 3 点。不自动排序、补点、平滑、归零或删除无效行；包含空值、非有限值、负值或变形回退时明确报错。需分析卸载、循环或存在明显回退的数据时，应先另存需要的单调加载段。

文本数字不支持千分位。小数点和小数逗号由用户明确选择，`0,005` 在逗号模式下为 0.005；逗号小数建议使用 TSV、TXT 或 Excel，避免与 CSV 分列冲突。Excel 原生数值不受文本小数选项影响。

## 计算定义

所有应力均为工程应力，采用初始尺寸。力为 N，尺寸为 mm，应力为 MPa；应变在计算中为无量纲，界面显示百分数。

### 拉伸

矩形截面积 `A = b h`，圆形截面积 `A = π d² / 4`；工程应力 `σ = F / A`。

- 实测应变直接使用仪器输出的工程应变。
- 标距内伸长使用 `ε = ΔL / L₀`。
- 横梁位移也按 `ΔL / L₀` 换算，但输出为**表观应变和表观模量**，没有补偿机架柔度、夹持滑移或夹具变形。

模量是在所选区间回归 `σ = E ε + b₀` 得到的斜率，输出 `E / 1000` GPa。不自动把回归模量等同于特定试验标准的弦模量。

拉伸积分使用实测首点至首次峰值的梯形积分 `∫σ dε`，单位 MJ/m³；不外推至零点，不将其称为断裂韧性或整个断裂过程的吸能。

## 结果与追溯

- 峰值使用**首次**最大力点；峰值应力与该点应变分开报告，不自动判为断裂。
- 指定应变处应力只在首点至首次峰值之间线性插值。重复应变采用首次出现的值，范围外显示空值，不外推。
- 人工确认后单独输出断裂应变和该点应力，保留确认点号。
- 统计使用样本标准差（n−1）和 CV；仅一条记录时标准差与 CV 留空。
- 保存标准单位下的完整曲线、尺寸、拟合参数、人工点号、源文件位置、导入映射、日期、备注、软件版本和算法版本。
- 新增数据库迁移 v4；历史迁移保持不变。打开旧库时沿用现有迁移前一致性备份机制。
- 历史列表展示保存时的结果缓存，载入和导出按保存输入使用当前算法重算。调整后再保存会创建新记录，原历史记录不被改写。

Excel 包含结果汇总、分组统计、参数与过程、完整曲线点和对比图；超单表行数时拆表。图最多显示前 20 条，每条约 5000 点，仅绘图抽样，原始数据与计算不抽样。CSV 为汇总表；PDF 为逐试样结果、过程和曲线图。导出使用原子写入，源数据文件不会被界面导出覆盖。
